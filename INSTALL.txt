LET'S SCORE — Professional multi-page redesign (corrected bundle)

Included files:
- /          Homepage
- courses        Course catalogue
- student        Student login / registration
- enrolment      ₹299 / ₹999 package, UPI and UTR submission
- dashboard      Student enrolments and approval status
- learn          Course resource catalogue
- resource       Dedicated page that opens each selected resource inside the course site
- teacher-control Current admin panel: payment requests, course/resource management, UTR approval and revisionary test controls
- teacher-control-insights Existing Student Results/insights admin page, preserved unchanged and linked from teacher-control
- styles.css          Shared responsive styling
- common.js           Student journey and Firebase integration

Install safely:
1. Back up the entire current GitHub Pages repository before uploading.
2. Extract this ZIP. Copy the contents of the lets_score_redesign folder into the same repository root as /.
3. This ZIP includes the current teacher-control admin panel. The existing Student Results/insights functionality is preserved in teacher-control-insights and linked from the main admin page. Keep both files. The insights page uses the existing authorised teacher account.
4. Keep existing revisionary-test, test-x, test-xi, test-xii and any other current test pages unchanged. This redesign does not replace those files.
5. Do not replace database.rules.json or modify Firebase rules as part of this front-end update.
6. Commit and wait for GitHub Pages to publish.
7. Test student login, payment request, UTR approval, course resources, videos on a ₹999-approved test account, and the Student Results/insights section in teacher-control.

Resource click behavior:
- Clicking a resource in learn opens resource with that selected course material.
- YouTube videos and supported Google Drive files are embedded on the dedicated resource page. An “Open original resource” link remains available for providers that block embedding.
- Videos are displayed only for approved ₹999 video-package access. ₹299 access does not unlock video lectures.

Firebase notes:
- Uses the existing Firebase project/config, existing courseResources/courseAccess/accessRequests/courses paths, UPI payee and WhatsApp support details from the current LET'S SCORE files.
- The legacy admin approval stores active access in courseAccess and the package choice in accessRequests; the student viewer checks both to determine the approved package.
- This bundle does not modify Firebase security rules. Test against the live Firebase project before announcing the update.
- Unlisted YouTube URLs are not DRM-protected and can be shared by anyone who obtains them.
