LET'S SCORE payment fix v2

1. Replace course.html in your GitHub Pages repository with this file.
2. Commit/push and wait for GitHub Pages to publish.
3. Firebase Console -> Authentication -> Sign-in method -> enable Anonymous.
   The current course page uses signInAnonymously(); if Anonymous sign-in is disabled,
   payment requests cannot be submitted. If you intend to use email/password accounts,
   the course page should instead use the authenticated account's UID.
4. Firebase Console -> Authentication -> Settings -> Authorized domains:
   ensure the GitHub Pages host is listed (for example, letsscore.github.io).
5. In the page, choose either ₹299 materials or ₹999 materials + recorded videos.
   The selected fee is reflected in the UPI link/QR and included in the payment request.
6. Test using a dummy reference first, then check Admin -> Payments & Access.

Important:
- This page submits the UTR as a pending request; it does not approve payments automatically.
- The admin must verify the payment and approve the request.
- This implementation uses anonymous Firebase identities. An anonymous identity is not
  a durable student login across browsers/devices. For persistent student accounts,
  use Firebase email/password authentication and make this page use that signed-in UID.
- Ensure deployed Realtime Database rules match the accessRequests/{courseId}/{uid}
  structure and validate package, fee, includesRecordedVideos, studentUid, courseId,
  status and requestedAt.
