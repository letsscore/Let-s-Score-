LET'S SCORE — Multi-page student experience redesign

Files included:
- index.html       New homepage
- courses.html     Course catalogue
- student.html     Separate registration/login page
- enrolment.html   Package selection, UPI payment and UTR submission
- dashboard.html  Student enrolment/access status
- learn.html       Course materials and approved-package video display
- styles.css       Shared responsive styling
- common.js        Existing Firebase project integration and student flow

Install:
1. Make a backup of the current GitHub Pages repository.
2. Upload these files to the same folder/root as the current site files.
3. Keep existing revisionary-test.html, test-x.html, test-xi.html, test-xii.html, teacher-control.html, database rules and other test files unchanged.
4. Do not replace teacher-control.html or database.rules.json as part of this front-end redesign.
5. Confirm the Firebase Realtime Database has the existing courseResources, courseAccess, accessRequests and studentProfiles paths expected by the site.
6. Test registration/login, course selection, ₹299 and ₹999 payment request, teacher approval, materials display and video visibility using test accounts before public launch.

Important:
- The existing Firebase config, course IDs, UPI payee details, and WhatsApp support number are retained from the current student page.
- This bundle does not change Firebase security rules or admin functionality.
- Unlisted YouTube URLs can still be shared by people who obtain them; strict video protection requires suitable protected hosting.
