LET’S SCORE — INTEGRATED REGISTRATION / LOGIN / COURSE / PAYMENT FLOW

Upload all files in this ZIP to the root of the existing GitHub repository, preserving existing files that are not included here.

STUDENT FLOW
1. Every non-admin link/button on the homepage opens register.html.
2. Registration creates Firebase Authentication credentials using a generated username and password, saves the student profile, signs out, and redirects to login.html.
3. Login validates Firebase Authentication and the saved student profile, then redirects to courses.html.
4. Course selection opens enrolment.html?id=COURSE_ID.
5. Free Class X Assamese Science opens the free notes/resources path. Paid courses show ₹299 materials-only and ₹999 materials + recorded-video package options, UPI payment details, QR, and UTR submission.
6. Payment request is saved at accessRequests/COURSE_ID/UID. Admin approval is managed in admin-control.html. Resource access depends on courseAccess/COURSE_ID/UID.

ADMIN FLOW
- Admin Login is linked from the homepage only and opens admin-control.html.
- Payments & access: approve, reject, revoke access, or delete a request.
- Resources: add chapter notes, NCERT solutions, question banks, model papers, and HTTPS video links by course.
- Courses: edit the course catalogue.
- Revisionary tests: publish/stop an HTML paper link.
- Student records: registration profiles.
- Test results: scores and submission timestamps.

IMPORTANT FIREBASE SETUP
- database.rules.json is the upgraded Realtime Database rules file. Review it before publishing in Firebase Console → Realtime Database → Rules.
- Enable Email/Password in Firebase Authentication.
- Add letsscore.online and www.letsscore.online under Authentication → Settings → Authorized domains.
- UPI ID: 7636047997@upi; WhatsApp receipt contact: 7002137940.
- No Firebase Storage upload or Blaze plan is required; resources are added using external HTTPS links.
- Revisionary tests are shown only to users with an active courseAccess record whose package is "videos" (₹999 package).
- Student profile rules now require username, contactEmail, mobile, district, classLevel, and medium. Existing older profiles missing these fields may need migration before they can use protected pages.
- Static HTML files hosted by GitHub Pages are public if someone knows their URL. Do not upload confidential answer keys as public HTML/PDF files.
