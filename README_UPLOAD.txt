LET'S SCORE — FIX FOR MISSING COURSE IMAGES
This version embeds all course images directly inside common.js. You do NOT need to upload an assets folder or any JPG/PNG files.

1. Open your existing GitHub repository.
2. Open common.js in the repository root.
3. Replace its entire contents with the common.js from this ZIP.
4. Commit to the main branch.
5. Wait for GitHub Pages deployment, then open https://letsscore.online/courses.html and refresh.

Only replace common.js. Do not delete other site files or change Firebase rules.
The image files are embedded as data URLs, so no separate image paths or folders are required.
