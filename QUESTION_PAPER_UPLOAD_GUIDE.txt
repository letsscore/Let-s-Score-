LET'S SCORE — HTML QUESTION PAPERS WITH PAID-COURSE ACCESS

FILES IN THIS UPDATE
- /: refreshed homepage copy; removes the Revisionary Tests item from the home navigation.
- teacher-control: upload-by-repository-path workflow; preview, publish/start, and stop HTML papers.
- revisionary-test: requires student sign-in and approved paid-course access before showing a test or paper link.

INSTALL
1. Extract this ZIP.
2. Upload/replace /, teacher-control, and revisionary-test in the root of your GitHub repository.
3. Keep common.js, styles.css, courses, student, dashboard, teacher-control-insights, and your existing test files.
4. Commit and wait for GitHub Pages to deploy.

PUBLISH AN HTML PAPER
1. Upload the HTML question paper to the repository root (or a subfolder).
2. Sign in at teacher-control.
3. Choose Class X, XI, or XII. Enter title, test ID, marks, and the relative HTML path, e.g. question-papers/class10-science-01.html.
4. Preview the paper, then select Publish & Start Test. Stop it when finished.

PAID COURSE ACCESS MAPPING
- Class X: class10-assamese-paid OR class10-english
- Class XI: class11-physics
- Class XII: class12-physics
The student must sign in using the account whose courseAccess record has active=true for the relevant course. Free Class X Assamese notes do not grant test access.

IMPORTANT SECURITY LIMITATION
GitHub Pages serves repository HTML files publicly. This update gates the revisionary-test page and hides test links from students without approved paid access, but it cannot make the raw HTML question-paper URL private. Anyone who already knows the direct URL may open it. Do not put confidential or high-stakes examination papers in a public GitHub repository. True file-level access control requires private storage or a protected server.

FIREBASE RULES
Your Realtime Database rules must allow signed-in students to read their own courseAccess/<courseId>/<uid> record, and allow reading examControl status. Do not enable public writes.

NOTE
The homepage mentions paid-course revisionary tests as a feature but does not include a Revisionary Tests navigation tab/link. This ZIP does not alter teacher-control-insights or the existing test-x, test-xi, and test-xii files. The HTML paper linked from the new page is not automatically connected to the scoring/result submission code in those older test pages.
